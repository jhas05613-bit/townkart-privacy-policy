How to request deletion

  3. Use the subject line “TownKart Account and Data Deletion Request”. Do not include your password or any one-time verification code.

Expected data affected: account/profile details, saved addresses and other personal data associated with your account, subject to applicable retention requirements. Some order or transaction records may need to be retained for lawful purposes; any retained data will be restricted to those purposes.

In-app option: If the TownKart app provides an in-app Delete Account option, use Profile or Account Settings and follow the confirmation flow. If that option is not present in the released app, it must be implemented before claiming full in-app deletion support in Google Play.
